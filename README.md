# แยกถูก รับถึงบ้าน (เดโม)

สมาชิกแนบรูปขยะรีไซเคิล → AI แยกชนิดและนับจำนวน → แจ้งพิกัดและจำนวนให้มารับ → ระบบจัดเส้นทางรถตามหมุดและเวลานัด → คนขับสแกน QR ของสมาชิกเพื่อยืนยันจุด ตรวจของ และบันทึกน้ำหนักจริง → ส่งของที่ศูนย์คัดแยก → ส่งต่อโรงงาน

## วิธีรัน

```bash
docker compose up -d --build
```

เปิด <http://localhost:8000>

เปิดใช้ AI แยกขยะจริง: คัดลอก `.env.example` เป็น `.env` ใส่ `ANTHROPIC_API_KEY` แล้วรัน `docker compose up -d` อีกครั้ง
ถ้าไม่ใส่ key ระบบใช้ผลแบบจำลอง (ไม่ได้อ่านจากรูป) และแสดงป้าย "AI: โหมดจำลอง" ที่มุมขวาบน

## หน้าจอ

| หน้า | ลิงก์ | ใช้ทำอะไร |
|---|---|---|
| สมาชิก | `/#member` | แนบรูป ตรวจจำนวนที่ AI นับ ปักหมุด เลือกเวลา แจ้งรับ และเปิด QR ให้คนขับสแกน |
| ผู้จัดรถ | `/#dispatch` | แผนที่เส้นทาง รายการแจ้งล่าสุดพร้อมพิกัดและจำนวน สั่งด้วยภาษาพูด |
| คนขับรถรับของ | `/#driver` | ลำดับจุดจอด นำทาง สแกน QR ยืนยันจุด ตรวจของ บันทึกน้ำหนักจริง และส่งของที่ศูนย์เพื่อปิดรอบ |
| บันทึก | `/#records` | ตารางคำขอทั้งหมด และดาวน์โหลด CSV |

## ขั้นตอนรับของของคนขับ

1. เลือกรถ แล้วกด "นำทาง" ไปจุดถัดไป
2. ถึงจุดแล้วกด "ถึงจุดแล้ว สแกน QR" และสแกน QR จากมือถือของสมาชิก เลือกได้ 3 ทาง: เปิดกล้อง แนบรูป QR หรือพิมพ์รหัส 6 ตัว ระบบปฏิเสธ QR ของจุดอื่น
3. ตรวจของให้ตรงกับรายการ แก้จำนวนที่รับจริง ใส่น้ำหนักจริง แล้วกด "ยืนยันรับของ" สมาชิกได้แต้มตามน้ำหนัก
4. เมื่อรับครบ กลับศูนย์คัดแยกแล้วกด "ส่งของที่ศูนย์แล้ว" ระบบสรุปน้ำหนักที่ต้องส่งต่อแต่ละโรงงาน

สถานะของคำขอ: รอรับ → ยืนยันจุดแล้ว → รับแล้ว → ส่งถึงศูนย์แล้ว

## AI อยู่ตรงไหน

1. **แยกและนับขยะจากรูป** (`app/ai.py`): Claude Vision ตอบเป็น JSON ตาม schema ได้แก่ ชนิดวัสดุ จำนวนชิ้น คำแนะนำก่อนส่ง และขนาดกอง
2. **สั่งจัดรถด้วยภาษาพูด** (`app/ai.py`): Claude แปลคำสั่งเช่น "รถคัน 2 เสีย" เป็น action ของระบบ

การคำนวณเส้นทาง (`app/routing.py`) ใช้ OR-Tools ไม่ใช่ LLM ส่วนน้ำหนักและมูลค่าคำนวณจากจำนวนชิ้นที่ AI นับ คูณน้ำหนักต่อชิ้นและราคาใน `app/config.py`

## โครงสร้าง

```
app/main.py      API และเสิร์ฟหน้าเว็บ
app/ai.py        เรียก Claude (แยกขยะ, แปลคำสั่ง) พร้อมโหมดจำลอง
app/routing.py   จัดเส้นทางรถแบบมีเวลานัดและความจุ
app/config.py    ชนิดวัสดุ ราคา ช่วงเวลา ศูนย์คัดแยก โรงงาน (ค่าตัวอย่าง)
app/seed.py      ข้อมูลตัวอย่าง 24 สมาชิก 20 คำขอ รถ 2 คัน
web/             PWA: index.html, app.js, styles.css, sw.js, manifest
```

แก้ไฟล์ใน `app/` หรือ `web/` แล้วเห็นผลทันทีโดยไม่ต้อง build ใหม่

## ข้อจำกัดของเดโม

- ระยะทางคิดจากเส้นตรงคูณ 1.35 และความเร็วเฉลี่ย 22 กม./ชม. ไม่ใช่ระยะถนนหรือจราจรจริง
- ราคารับซื้อ ตำแหน่งศูนย์คัดแยก และโรงงาน เป็นค่าตัวอย่าง
- น้ำหนักประมาณ = จำนวนชิ้นที่นับได้ x น้ำหนักเฉลี่ยต่อชิ้นของวัสดุ (ค่าตัวอย่างใน `app/config.py`) คนขับยืนยันน้ำหนักจริงตอนรับ
- ความจุรถคิดจากพื้นที่ตามขนาดกอง S/M/L (เทียบเป็นถุงหิ้ว) ไม่ได้คิดจากน้ำหนัก
- ไม่มีระบบล็อกอิน ใช้การเลือกสมาชิกจากรายการแทน จึงยังไม่ได้จำกัดว่าใครเปิดดู QR ของคำขอได้
- การเปิดกล้องสแกน QR ใช้ได้เฉพาะบน `localhost` หรือ HTTPS ถ้าเปิดไม่ได้ให้แนบรูป QR หรือพิมพ์รหัสแทน
- PWA ติดตั้งและใช้ตำแหน่งปัจจุบันได้เฉพาะบน `localhost` หรือ HTTPS ถ้าจะเปิดจากมือถือต้องมี HTTPS
